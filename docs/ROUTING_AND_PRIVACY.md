# Routing and Privacy

## 비행기 경로

화면의 비행기 선은 실제 항공사의 항로가 아닙니다. 출발지와 목적지의 위치 관계를 아이가 쉽게 이해하도록 곡선으로 보여주는 교육용 표현입니다.

## 직선거리

`geo.js`에서 Haversine 공식을 사용해 지표면상의 두 좌표 사이 대권거리 근사값을 계산합니다.

## 예상 비행시간

항공편 검색 API를 사용하지 않기 때문에 거리를 평균 순항속도로 나누고 이착륙/공항 접근에 해당하는 여유시간을 더한 교육용 예상값입니다.

## 육상거리

1. 가능한 경우 OSRM driving route 요청
2. 경로가 반환되면 실제 도로망 기반 거리와 소요시간 표시
3. 경로가 없거나 API가 실패하면 `geo.js`의 국가·국경·대륙 관계 기반 fallback 사용
4. 섬/대륙 간 등 현실적인 육상 연결이 어렵다면 계산 어려움 표시

따라서 육상거리는 내비게이션용으로 사용하면 안 됩니다.

## 위치정보

브라우저의 `navigator.geolocation`은 사용자가 버튼을 눌렀을 때만 요청합니다.

정확한 도로경로 기능을 사용할 때는 출발/도착 좌표가 공개 OSRM 라우팅 서비스로 전송될 수 있습니다. GlobeHop 프로젝트 자체는 별도 서버가 없고 사용자의 정밀 위치를 서버 데이터베이스에 저장하지 않습니다.

## 운영 환경 권장

공공 데모 API는 서비스 보장(SLA)이 없는 경우가 많습니다. 트래픽이 증가하는 실제 서비스에서는 다음 중 하나를 권장합니다.

- 자체 OSRM 인스턴스
- 상용 routing API
- 서버리스 프록시

API 키가 필요한 서비스를 선택할 경우 GitHub Pages 프론트엔드 소스에 비밀키를 직접 넣지 마세요.
