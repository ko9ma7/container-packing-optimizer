# V7 — 확대/축소와 반응형 지도 가독성 수정

## 수정 이유
V6에서는 3D 지구 텍스처 자체에 `대한민국`, `일본` 같은 국가명을 직접 그렸습니다. 이 글자는 지구 표면의 일부였기 때문에 카메라가 가까워질수록 글자도 함께 커졌고, 지도와 주변 장소를 가리는 문제가 있었습니다.

## V7 수정

### 3D
- 국가명을 WebGL 지구 텍스처에 직접 그리는 코드를 제거했습니다.
- 국가명은 Canvas overlay의 screen-space UI로만 표시합니다.
- 확대/축소해도 라벨의 화면상 크기는 거의 일정합니다.
- 화면 폭에 따라 라벨 크기를 소폭 조정합니다.
- 작은 모바일 화면에서는 더 작은 compact label을 사용합니다.
- 가까운 regional route 자동 시점은 V6보다 약간 넓혀 주변 국가와 장소가 같이 보이게 했습니다.
- 3D 최소 줌 거리를 제한해 지구 표면이 과도하게 화면을 채우지 않도록 했습니다.
- `+ / -` 버튼으로 3D도 확대·축소할 수 있습니다.

### 2D
- 마우스 휠 확대/축소
- 터치 pinch 확대/축소
- 마우스/터치 drag로 지도 이동
- `+ / -` 버튼 확대/축소
- `전체 보기`로 세계 전체 복귀
- 커서 위치를 기준으로 zoom하므로 보고 있던 지점이 화면에서 튀지 않습니다.
- 마커/비행기 크기는 viewBox 확대율에 역비례해 조정하여 화면상 크기가 갑자기 커지지 않습니다.
- 드래그 직후 국가/도시가 실수로 클릭되는 것을 막는 click suppression을 추가했습니다.

## 반응형 정책
- PC: 나라 라벨과 경로 라벨을 읽기 쉬운 크기로 유지
- 태블릿: controls 축소, 라벨 최대 폭 제한
- 모바일: compact label, 32px zoom button, 긴 interaction hint 숨김
- 모든 지도 텍스트/버튼은 지리 zoom이 아니라 화면 UI scale을 기준으로 표시합니다.
